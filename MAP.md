# MAP — YT Cartell Studio

Архітектурна карта проєкту, структура модулів та взаємозв'язки компонентів для агентів та інженерів Synapse Group.

---

## 1. Зона та відповідальність
- **Призначення:** Автономна десктопна студія повного циклу для автоматизації створення контенту на YouTube та Shorts (Ідея / Сценарій → План персонажів та локацій → Розкадровка → Генерація відео та озвучки → Нелінійний монтаж з субтитрами та обкладинкою).
- **Власник / Напрямок:** Synapse Group Media & YouTube Automation Division.
- **Статус репозиторію:** Ізольований локальний форк (відв'язаний від оригінального репозиторію upstream).
- **Офіційний сайт та довідка:** [https://gitkalenyuk.github.io/yt-cartell-studio/](https://gitkalenyuk.github.io/yt-cartell-studio/)
- **Технологічний стек:**
  - **Мова:** Go 1.23+
  - **GUI Framework:** [Gio UI](https://gioui.org) (нативне апаратне прискорення через GPU/Vulkan/DirectX/Metal, без Chromium/Electron).
  - **Обробка медіа:** FFmpeg.
  - **ШІ-провайдери:** Gemini, G-Labs (Google Flow / Nano Banana / Veo), ElevenLabs (TTS), Whisper (STT).
  - **Платформи:** Windows 10/11 (x64), macOS, Linux.

## 2. Структура каталогів та модулів проєкту

```
/root/yt-cartell/
├── main.go                 # Точка входу десктопної програми
├── go.mod / go.sum         # Залежності Go модулів
├── build.sh / build.bat    # Скрипти компіляції під Linux/macOS та Windows
├── docs/                   # Посібники користувача та документація
│   └── GUIDE.md            # Детальний посібник користувача (п'ять кроків, налаштування)
├── cmd/                    # Допоміжні CLI утиліти
│   ├── guikit/             # Тестовий стенд інтерфейсу
│   ├── guishots/           # Генерація скріншотів GUI
│   └── stylegen/           # Генератор пресетів стилів
├── internal/               # Внутрішня бізнес-логіка студії
│   ├── appui/              # Основні екрани програми (Головна, Проєкт, Монтаж, Черга, Налаштування)
│   ├── codeanim/           # Модуль анімації графіків та схем кодом
│   ├── config/             # Керування конфігурацією та безпекою API-ключів
│   ├── cover/              # Студія створення та оформлення обкладинок (12 шаблонів)
│   ├── deps/               # Керування системними залежностями
│   ├── gemini/             # Клієнт Google Gemini API для аналізу сценаріїв та відео
│   ├── gen/                # Движок генерації планів, персонажів та сцен
│   ├── glabs/              # Інтеграція з генераторами відео/зображень (G-Labs/Veo)
│   ├── gui/                # Базові віджети, теми (Світла, «Вечір», системна) та стилі
│   ├── llm/                # Уніфікований інтерфейс взаємодії з мовними моделями
│   ├── nle/                # Движок нелінійного монтажу (таймлайн, 23 переходи, ефекти, субтитри)
│   ├── player/             # Вбудований відеоплеєр попереднього перегляду
│   ├── providers/          # Підключення сторонніх провайдерів генерації
│   ├── reference/          # Модуль ремейку відео за посиланням з YouTube
│   ├── stt/                # Розпізнавання мови (Whisper)
│   ├── studio/             # Ядро студії: керування проєктами, сценами, чергою та «Автопілотом»
│   ├── tgbot/              # Telegram-бот для моніторингу статусу генерацій
│   └── tts/                # Движок синтезу мовлення (озвучка диктора та репліки героїв)
├── README.md               # Документація студії
├── TODO.md                 # Пріоритетні завдання та беклог
├── нотатки та правки.txt   # Відкриті поточні правки за регламентом
├── JOURNAL.md              # Журнал версій та рішень
├── MAP.md                  # Архітектурна карта (цей файл)
└── ROADMAP.md              # Дорожня карта впровадження
```

## 3. Збереження даних та ізоляція секретів
- **Проєкти користувача:** За замовчуванням зберігаються в каталозі `Documents/YT Cartell Studio/projects/<id>/`.
- **Конфігурація та API-ключі:** Зберігаються локально в `%AppData%/YT Cartell Studio/config.json`.
- Жодні ключі чи чутливі дані не виходять за межі локальної машини розробника.
