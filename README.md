# YT Cartell Studio

Відкрита десктопна студія, де історія стає відео: **історія → план → кадри → відео й озвучка →
монтаж → готовий `.mp4`** з субтитрами й обкладинкою для YouTube. Окрема програма з власним вікном
(Go + [Gio](https://gioui.org)) — без браузера, без Node.js і без жодного входу чи реєстрації.
Windows, macOS, Linux.

Кожне відео — проєкт із п'яти кроків. Можеш пройти їх разом зі студією й виправити все, що написав
ШІ, ще до того, як витрачаються кредити. А можеш вставити історію й натиснути **«Автопілот»** —
студія сама зробить план, кадри, кліпи, озвучку, монтаж і обкладинку.

Генерацію робиш **своїми** сервісами й ключами (текст, картинки, відео, озвучка): студія нічого не
продає й нікуди не передає твої ключі — вони лежать лише на твоєму комп'ютері.

Ліцензія — [MIT](LICENSE). Спільнота — [YT Cartell у Telegram](https://t.me/YT_cartell).

## Що вміє

- **П'ять кроків або «Автопілот».** Сценарій → план (персонажі, локації, сцени) → розкадровка →
  відео й озвучка → монтаж. Автопілот проходить усе сам і повторює те, що не вдалося; прогрес — у
  «Черзі».
- **Однакові герої в усіх сценах:** спершу обличчя героїв і місця, потім кадри з ними. Можна додати
  свої фото героїв, місць і зразок стилю («Матеріали»).
- **Перезняти за прикладом.** Посилання на YouTube + побажання → Gemini дивиться відео й розбирає
  його сцена за сценою, а студія знімає новий фільм: точна копія, близько до оригіналу або лише
  структура й темп.
- **Профілі** — готові набори налаштувань (тривалість, формат, звук, стиль, жанр, голос, мова, тон,
  монтаж): «YouTube історія 16:9», «Shorts / Reels 9:16», «Дитяча казка», «Документальне пояснення»
  і свої; профіль можна скласти з опису або зберегти з проєкту.
- **72 стилі, 37 жанрів і ніш**, 10 варіантів камери, 4 темпи (аж до «Дуже швидкий (Shorts)»),
  10 тонів оповіді, 93 мови фільму — окремо від мови, якою пишеш.
- **Звук і що в кадрі:** озвучка диктора, голос у відео (герої говорять голосами відеомоделі) або
  без голосу; персонажі, без людей, моушн-графіка чи змішано, з анімованим текстом у кадрі.
- **Анімація кодом** — сцени, намальовані не відеомоделлю, а кодом (графіки, схеми, мапи): зокрема
  «Історія на мапі» — анімована старовинна мапа з фігурками, маршрутами й кольоровими країнами, рух
  камери «Рух мапою», субтитри фразами по 1–4 слова.
- **Розкадровка 3×3 і ланцюжок кадрів** — дев'ять моментів дії на сцену; кожна наступна сцена
  продовжує останній кадр попередньої.
- **Монтаж із таймлайном:** порядок сцен, обрізка кліпів і голосу, 23 переходи, 12 ефектів руху,
  15 фільтрів, 9 стилів субтитрів, фонова музика з приглушенням під голосом, гучність −14 LUFS.
- **Експорт у редактори:** DaVinci Resolve, Premiere Pro, Final Cut Pro, CapCut, Kdenlive / Shotcut,
  OpenTimelineIO.
- **Студія обкладинок:** 12 шаблонів, 8 шрифтів із повною українською абеткою, перегляд «як
  побачать на YouTube».
- **Переклад проєкту** іншою мовою, **своя озвучка** (твій запис + розпізнавання мови або текст із
  таймкодами), **диктування** історії мікрофоном.
- **Telegram-бот** — твій власний бот: сповіщення й керування студією з телефона (новий проєкт,
  «За прикладом», черга, готове відео в чат).
- **Перенесення налаштувань** одним зашифрованим файлом `.ytcs`, **вбудоване оновлення** з GitHub
  Releases із перевіркою SHA-256.

## Які сервіси потрібні

Усе необов'язкове й твоє: студія відкривається й без жодного ключа (можна роздивитися інтерфейс),
а для генерації підключаєш те, чим уже користуєшся. Ключі зберігаються лише в
`%AppData%\YT Cartell Studio\config.json` (macOS — `~/Library/Application Support/YT Cartell Studio`),
у журнал і повідомлення про помилки потрапляють лише маски.

| Для чого | Варіанти |
|---|---|
| **Текст** (сценарій, план, промти) | будь-який OpenAI-сумісний сервер (OpenAI, OpenRouter, локальний шлюз на кшталт `http://127.0.0.1:8317/v1`…), Anthropic, Ollama, Azure OpenAI або Google Gemini |
| **Кадри й відео** | G-Labs Studio (Webhook API), Google AI Studio (Gemini / Veo, Nano Banana) або «Своє API»: OpenAI, fal.ai, Replicate, Runway, Luma, MiniMax, RoyalTechno чи будь-який сервіс через універсальний JSON-опис |
| **Озвучка** | ElevenLabs, Cartesia, OpenAI (або сумісний), Google Cloud, Azure, MiniMax, Fish Audio, Lumean або свій сервер |
| **Розпізнавання мови** («Своя озвучка», мікрофон) | ElevenLabs Scribe, Whisper-сумісний сервер, AssemblyAI, Deepgram, Google або локально whisper.cpp — без ключа |
| **«Перезняти за прикладом»** | ключ Google AI Studio (або текстовий сервіс, що вміє дивитися YouTube) |
| **Telegram-бот** | токен свого бота від @BotFather |
| **FFmpeg** (монтаж, мініатюри, мікрофон) | ставиться кнопкою «Встановити автоматично» або вручну |

Найпростіше підключити все через **Налаштування → Підключення → «Помічник підключення»**: встав
будь-який текст з адресами й ключами — студія сама розбере, перевірить і запропонує план.

Що завантажується під час роботи (лише на твою кнопку, з офіційних джерел, зі звіркою контрольної
суми): FFmpeg (Windows — gyan.dev, Mac — Homebrew або martin-riedl.de) і whisper.cpp з моделлю для
локального розпізнавання. У програму вони не вбудовані.

## Як запустити готову програму

1. Завантаж збірку з розділу **Releases** репозиторію: `YT-Cartell-Studio-<версія>-windows-x64.exe`
   або zip для macOS (Apple Silicon, Intel чи універсальний).
2. **Windows:** запусти exe. Якщо з'явиться «Windows захистив ваш ПК» — «Докладніше» → «Виконати в
   будь-якому разі» (програма не підписана сертифікатом).
   **macOS 13+:** розпакуй, перетягни `YT Cartell Studio.app` у «Програми» й відкрий правим кліком →
   «Відкрити» (або `xattr -dr com.apple.quarantine "/Applications/YT Cartell Studio.app"`).
3. Студія відкриється одразу на Головній і покаже короткий тур. Далі —
   **Налаштування → Підключення**: підключи свої сервіси (поля зберігаються самі, у кожної картки є
   «Перевірити») і FFmpeg.
4. На Головній встав історію → **«Автопілот»** або **«Покроково»**.

Проєкти лежать у `Документи\YT Cartell Studio\projects`, налаштування й журнал (`studio.log`) — у
`%AppData%\YT Cartell Studio`. Докладно — [`docs/GUIDE.md`](docs/GUIDE.md).

## Як зібрати з вихідного коду

Потрібен [Go 1.27+](https://go.dev/dl/). Тести й збірка не потребують жодних ключів чи мережі
(крім завантаження Go-модулів).

### Windows

C-компілятор не потрібен (Gio й аудіо збираються без cgo):

```bat
build.bat
```

або в Git Bash `./build.sh`, або вручну:

```sh
CGO_ENABLED=0 go build -trimpath -ldflags "-s -w -H windowsgui" -o YT-Cartell-Studio.exe .
```

Іконка й версія exe — у `rsrc_windows_amd64.syso` (Go підхоплює його сам). Щоб перегенерувати з
`internal/assets/icon256.png`, видали цей файл і запусти `build.bat` (один раз потрібен інтернет для
[go-winres](https://github.com/tc-hib/go-winres)).

### macOS

На Mac Gio потребує cgo, тож збирай на самому Mac (macOS 13 Ventura або новіша):

```sh
xcode-select --install          # Xcode Command Line Tools: clang, lipo, codesign, iconutil
brew install go                 # Go 1.27+
bash build-mac.sh               # .app для Apple Silicon, Intel і універсальний → dist/mac/*.zip
```

Або просто `./build.sh` — один бінарник для поточної архітектури. Покроково — у
[`docs/BUILD-MAC.md`](docs/BUILD-MAC.md); готова інструкція для ШІ-агента, що збере й встановить
програму сам, — [`docs/CLAUDE-MAC-BUILD.md`](docs/CLAUDE-MAC-BUILD.md).

### Linux

Збирається `./build.sh` (cgo; потрібні gcc і dev-пакети Gio). Debian/Ubuntu:

```sh
sudo apt install gcc pkg-config libwayland-dev libx11-dev libx11-xcb-dev libxkbcommon-dev \
  libxkbcommon-x11-dev libgles2-mesa-dev libegl1-mesa-dev libffi-dev libxcursor-dev \
  libxfixes-dev libvulkan-dev
./build.sh
```

Для вікон вибору файлів потрібен `zenity` або `kdialog`. Linux перевірено найменше — пиши, що не так.

### Перевірка коду

```sh
CGO_ENABLED=0 go vet ./... && CGO_ENABLED=0 go test ./...
```

Тести ходять лише на локальні mock-сервери — платні сервіси ніколи не викликаються. Скриншоти всіх
екранів без вікна: `go run ./cmd/guishots` (тимчасова копія даних, пише в `screenshots/new`);
галерея компонентів — `go run ./cmd/guikit -out guikit-out`.

## Як переробити під себе з ШІ

Код написано так, щоб його було зручно міняти разом із ШІ-агентом. Відкрий цю папку в
[Claude Code](https://claude.com/claude-code), Codex, Cursor чи іншому агенті й почни з того, щоб
він прочитав [`ARCHITECTURE.md`](ARCHITECTURE.md) — це контракт проєкту: правила (Go 1.27,
`CGO_ENABLED=0`, без нових залежностей, UI українською на «ти»), пакети, їхній API, граф імпортів і
як тестувати. Дизайн інтерфейсу — [`GUI.md`](GUI.md) і [`DESIGN.md`](DESIGN.md).

Приклади запитів:

- «Прочитай ARCHITECTURE.md. **Додай новий стиль** кадрів "Пластилін" з превʼю, як інші стилі.»
- «**Підключи мій сервіс озвучки**: ось документація API … Зроби його пресетом, як Cartesia, з
  перевіркою ключа й списком голосів.»
- «**Зроби свій профіль** "Мій канал про космос": 9:16, 60 с, стиль … голос … — і додай його до
  стартових профілів.»
- «Додай мову інтерфейсу англійську» або «Зроби ще один шаблон обкладинки, як "shorts-top"».
- «Підключи мій сервіс відео через "Своє API" — ось його документація.» (часто вистачає й самої
  програми: «Своє API» → «Налаштувати з документації (ШІ)»).

Попроси агента наприкінці прогнати `go vet ./...` і `go test ./...` і подивитися PNG змінених
екранів (`GUISHOTS=<папка> go test ./internal/appui/<екран> -run TestShots`).

## Структура проєкту

```
main.go                 запуск: журнал → налаштування → рушій → вікно
internal/studio/        рушій: проєкти, задачі, планувальник, виробництво, монтаж, автопілот, черга
internal/appui/         вікно й екрани (home, project, produce, montage, settings, dialogs, queue…)
internal/gui/           власний UI-кіт «warm app» на Gio
internal/config/        налаштування (config.json), профілі, перенесення налаштувань
internal/llm, gemini, glabs, providers, tts, stt, dictate, reference   підключення до сервісів
internal/media, nle, cover, player, codeanim                         FFmpeg, експорт, обкладинки, анімація кодом
internal/notify, tgbot  Telegram: сповіщення й керування своїм ботом
internal/update         оновлення з GitHub Releases
cmd/guishots, guikit    скриншоти екранів і галерея компонентів (без вікна)
cmd/stylegen            інструмент розробника: генерує превʼю стилів через твій G-Labs
```

Повний опис — [`ARCHITECTURE.md`](ARCHITECTURE.md).

## Оновлення й форки

Студія сама перевіряє нові версії (раз на 6 годин, можна вимкнути) у GitHub Releases репозиторію
`gitkalenyuk/yt-cartell-studio`: «Оновлення» в меню зліва → «Завантажити й встановити» →
«Перезапустити зараз». Файл звіряється з `SHA256SUMS.txt` релізу; проєкти й налаштування лишаються.

Робиш свій форк і публікуєш свої релізи — направ оновлення на свій репозиторій під час збірки:

```sh
# будь-яка збірка
go build -ldflags "-X ytcartell/internal/update.Owner=я -X ytcartell/internal/update.Repo=моя-студія" …
# або змінні для build.bat / build.sh
UPDATE_OWNER=я UPDATE_REPO=моя-студія ./build.sh
# релізні скрипти роблять це самі
.\release.ps1 -Notes notes.md -Repo я/моя-студія       # Windows: exe + SHA256SUMS.txt → GitHub Release
bash build-mac.sh --upload --repo я/моя-студія          # Mac: zip-и в той самий реліз
```

Версія — у `internal/version/version.go` (зараз **2.1.0**). Як зробити внесок — [`CONTRIBUTING.md`](CONTRIBUTING.md).
