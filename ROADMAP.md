# ROADMAP — YT Cartell Studio

Дорожня карта розвитку та інтеграції автономної відеостудії в інфраструктуру Synapse Group.

---

### 🟢 Етап 1: Розгортання та локальний аудит (Поточний)
- [x] Клонування репозиторію студії в теку `/root/yt-cartell/`.
- [x] Повне відв'язування від апстрім-репозиторію (`remote origin` видалено).
- [x] Підключення офіційної документації та регламенту холдингу Synapse Group.
- [ ] Аудит Go-модулів та залежностей компіляції (`Gio UI`, `FFmpeg`).
- [ ] Перевірка роботи конфігуратора ключів та збереження стану.

### 🟡 Етап 2: Тестування пайплайнів генерації
- [ ] Тестовий прогін сценарію в режимі «Автопілот» на тестових ключах.
- [ ] Перевірка узгодженості персонажів (character consistency) за допомогою референсних фото та @тегів.
- [ ] Тестування режиму «Перезняти за прикладом» (аналіз відео за посиланням з YouTube).
- [ ] Оцінка якості монтажного модуля, автоматичних субтитрів та накладання музики.

### 🔵 Етап 3: Кастомізація під канали холдингу
- [ ] Створення фірмових профілів Synapse Group для форматів Shorts (9:16) та класичних історій (16:9).
- [ ] Розширення бібліотеки шаблонів обкладинок новими фірмовими лейаутами.
- [ ] Додавання власних аудіо-треків та пресетів дикторських голосів.

### 🟣 Етап 4: Серверна автоматизація та API
- [ ] Дослідження можливості запуску черги генерацій у фоновому сервісному режимі без GUI.
- [ ] Підключення Telegram-бота сповіщень до робочого чату студії.
- [ ] Інтеграція з іншими медіа-ботами холдингу.
