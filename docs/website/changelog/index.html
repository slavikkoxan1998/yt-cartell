2.1.0 — відкритий код, без входу

Жовтень 2026 · релізи на GitHub

  • Безкоштовно й з відкритим кодом. Код студії — на GitHub під ліцензією MIT. Тепер програма доступна кожному вайбкодеру: форкай, відкривай у Claude Code, Codex чи Cursor і переробляй під себе. Довідник
  • Без входу й підписок. Вхід через Telegram і перевірку підписки на канал і чат прибрано — студія відкривається одразу. Канал YT Cartell лишається для новин, за бажанням.
  • Готові збірки для Windows і macOS — як і раніше, у релізах цього репозиторію; оновлення з програми працює так само.
  • Свій Telegram-бот для сповіщень і керування з телефона лишився без змін.

2.0.3 — без заглушок, будь-який провайдер, мультиголос

5 жовтня 2026 · Windows · реліз на GitHub

Збірки для macOS у цьому релізі поки немає — для Mac найновіша версія 2.0.2.

Без заглушок і зниклих сцен

  • Сцени більше не випадають з монтажу й не підміняються мовчки застиглим кадром. Перед монтажем студія показує невдалі сцени з точною помилкою сервісу й питає: змонтувати без них, з кадром замість відео чи зупинитись. Довідник
  • Точні помилки всюди: сервіс, код і відповідь — на картці сцени, у черзі, в Telegram.
  • Кліпи більше не обрізає в кінці: довжина враховує переходи й реальний темп мови.
  • Omni Flash: якщо сцену відхилили, студія один раз пробує ще — без розкадровки, лише з кадром.

Будь-який провайдер

  • Текст: адреса без /v1 підбирається сама; Anthropic, Ollama, Azure OpenAI; вибір способу авторизації. Довідник
  • Будь-яка озвучка й розпізнавання мови через «Власний сервер» / «Своє API» з шаблонами.
  • Lumean — повноцінний сервіс озвучки (потрібен ключ із пресетом full).
  • «Помічник підключення»: вставляєш адреси, ключі, посилання — студія розпізнає й налаштує все сама; ключі нейронці не передаються. Довідник
  • Каталоги з готовими параметрами: 199 моделей відео, 188 моделей кадрів, 144 моделі, голоси й сервери озвучки, 36 текстових сервісів — «Вибрати з каталогу». Довідник

Мультиголос

  • Диктор, Диктор 2 і 3 та свій голос для кожного героя; студія сама розподіляє репліки й голоси, субтитри можна фарбувати кольором мовця. Довідник

І ще

  • Telegram-бот: список невдалих сцен із кнопками рішення. Довідник
  • Нова озвучка довша за кліп — кліп позначається «перезняти?».

2.0.2 — ключі Google AQ.

2 жовтня 2026 · Windows і macOS · реліз на GitHub

  • Нові ключі Google AI Studio: з травня 2026 Google видає ключі формату AQ.… замість AIza…. Тепер студія приймає обидва — у «Підключення → Google», пачкою й у диктуванні. Довідник
  • macOS: вікно відкривається надійно, навіть якщо Mac щойно прокинувся без активного дисплея.
  • Точніші підказки в «Перезняти за прикладом» і для розкадровки 3×3 через Google.

2.0.1 — велике оновлення

2 жовтня 2026 · Windows і macOS · реліз на GitHub

Нові режими

  • Голос у відео — герої говорять у кадрі голосами самої відеомоделі (Veo, Omni Flash), без окремої озвучки; без голосу — лише музика й звуки. Довідник
  • Що в кадрі: персонажі, без людей, моушн-графіка або змішано; +4 стилі й +4 жанри.

Перезняти за прикладом

  • Посилання на YouTube і твоє побажання — Gemini розбирає відео сцена за сценою, студія робить новий фільм: точна копія, близько до оригіналу або лише структура й темп. Довідник

Керування й зручність

  • Мікрофон на Головній. Довідник
  • Telegram-бот — новий проєкт текстом чи голосовим, проєкти, черга, прогрес наживо, відео в чат. Довідник
  • Експорт у DaVinci Resolve, Premiere Pro, Final Cut Pro, CapCut, Kdenlive / Shotcut, OpenTimelineIO. Довідник
  • Експорт і імпорт налаштувань одним зашифрованим файлом. Довідник

Сервіси

  • «Своє API» для будь-якого сервісу: шаблони, опис JSON або «Налаштувати з документації (ШІ)»; пресет RoyalTechno. Довідник
  • Google: Gemini Omni Flash, розкадровка 3×3 і ланцюжок кадрів через Google і RoyalTechno.
  • Озвучка: свої ключі в кожного сервісу, ключі пачкою, голос за ID, AssemblyAI для розпізнавання. Довідник
  • G-Labs: без безнадійних повторів, зупинка покинутих задач, Omni Flash 4 і 6 с без Ultra.

І ще

  • FFmpeg одним кліком, до 20 сцен одночасно, гучність −14 LUFS, захист від двох відкритих копій. Довідник

2.0.0 — перша публічна версія

1 жовтня 2026 · Windows і macOS · реліз на GitHub

  • Від історії до готового відео в п'ять кроків; автопілот робить план, кадри, кліпи, озвучку, монтаж і обкладинку сам.
  • Профілі налаштувань і профіль за описом каналу.
  • 93 мови, 67 стилів із живими прикладами, 32 жанри; свої фото героїв і місць.
  • Omni Flash: розкадровка 3×3 і ланцюжок кадрів; динамічна довжина сцен.
  • Монтаж: таймлайн, 23 переходи, 12 ефектів руху, 15 фільтрів, 8 стилів субтитрів; студія обкладинок із 12 шаблонами.
  • Переклад проєкту, своя озвучка з таймкодами або розпізнаванням, черга й сповіщення в Telegram, оновлення з програми.
  • Відеоурок до версії 2.0.0.
