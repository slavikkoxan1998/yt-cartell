Текст: п'ять протоколів

Налаштування → Підключення → «Текст і сценарій» → «Хто пише текст»: «OpenAI-сумісний», «Anthropic», «Ollama», «Azure», «Google Gemini» (у вузькому вікні — «OpenAI» і «Gemini»). Далі адреса, API-ключ, модель і «Перевірити». Не знаєш адресу — «Вибрати з каталогу»: 36 сервісів і локальних серверів.

ПротоколЩо підключати
«OpenAI-сумісний»CarteLink, OpenAI і будь-який сервіс із /chat/completions.
«Anthropic»Claude через Anthropic API; ключ іде в заголовку x-api-key.
«Ollama»Локальні моделі Ollama.
«Azure»Azure OpenAI. Для адреси деплойменту з'явиться поле «api-version» (за замовчуванням 2024-10-21).
«Google Gemini»Ключ Google AI Studio.

Адреса без /v1 — не біда

Під полем підказка: «Будь-який OpenAI-сумісний сервіс. /v1 чи /api/v1 студія знайде сама.» «Перевірити» пробує адресу як є, потім із /v1, /api/v1 і /openai/v1. Знайшлася робоча форма — студія напише «Адресу виправлено: … → …» і збереже її. Вставив повну адресу запиту (…/chat/completions) — теж спрацює.

Авторизація

Поле «Авторизація» — як ключ іде на сервер. Зазвичай досить «Авто»: «Перевірити» сам знайде потрібний заголовок.

ВаріантЩо робить
«Авто (Bearer)»Студія сама підбирає заголовок під час перевірки. Для Anthropic — «Авто (x-api-key)», для Azure — «Авто (api-key)».
«Authorization: Bearer»Ключ у заголовку Authorization: Bearer ….
«x-api-key»Ключ у заголовку x-api-key.
«api-key (Azure)»Ключ у заголовку api-key.
«Без ключа»Для серверів, яким ключ не потрібен.

Якщо спрацював інший заголовок, студія напише «Ключ працює в заголовку … — збережено».

Ключ у параметрі адреси (query) можна задати лише в описі API для «Своє API» чи «Власного сервера»: bearer, header:Назва, query:назва або none.

Якщо не працює

«Перевірити» показує панель «Не вдалося» з точною помилкою: що відповів сервіс і з яким кодом, сам запит (ключі прибрано), «Відповідь», «Підказка» і «Спробувано» — кожну адресу, яку студія перепробувала.

Що бачишЩо перевірити
«…відхилив ключ (401)»Ключ і поле «Авторизація».
«…відповів помилкою 404»Адресу: найчастіше бракує /v1 (напр. https://сервер/v1) або /api/v1.
Немає зв'язку з локальною адресоюЧи запущені CarteLink чи Ollama на цьому комп'ютері.

Ті самі точні помилки є на картках сцен, у черзі й у Telegram — Невдалі сцени і точні помилки.

Озвучка: будь-який сервер

«Озвучка» → сервіс «Власний сервер» → «Опис API озвучки». Почни з «Шаблон…»:

  • «OpenAI-сумісний /audio/speech»
  • «ElevenLabs-сумісний»
  • «Lumean (замовлення за шаблоном)»
  • «Простий синхронний: POST → аудіо або посилання»
  • «Асинхронні задачі (каркас)»

Або «Налаштувати з документації (ШІ)» → «Скласти опис» → переглянь «Чернетку від ШІ» → «Зберегти опис». Як влаштований опис API — у розділі «Своє API». Готові сервіси з параметрами — у каталозі озвучки.

Розпізнавання мови: «Своє API»

«Розпізнавання мови» → «Своє API» → «Опис API розпізнавання». Шаблони: «OpenAI-сумісний /audio/transcriptions», «ElevenLabs Scribe», «Простий синхронний: POST → текст зі словами», «Асинхронні задачі (каркас)». Так само є «Налаштувати з документації (ШІ)».

Lumean

Lumean — окремий сервіс у списку «Озвучка». Він озвучує моделями ElevenLabs (за замовчуванням eleven_multilingual_v2, мови поза її 29 — через eleven_v3) і працює через замовлення: студія ставить задачу й забирає готове аудіо.

  1. На lumean.app: «Розробникам» → «API-ключі» — створи ключ із пресетом full.
  2. У студії: «Озвучка» → сервіс «Lumean» → встав ключ → «Перевірити».

Ключу потрібні права orders.write, orders.download, templates.write, voices.read (і billing.read, щоб бачити баланс) — саме їх дає пресет full. Без них студія скаже, якого права бракує, напр. «Lumean: ключу бракує прав (403) — …».

У «Власному сервері» є шаблон «Lumean (замовлення за шаблоном)», але простіше — сервіс «Lumean» у списку.

Питання

Як підключити CarteLink?

«OpenAI-сумісний», адреса на кшталт http://127.0.0.1:8317/v1, ключ і модель → «Перевірити». CarteLink має бути запущений.

Ollama просить ключ?

Ні — у «Авторизації» можна вибрати «Без ключа».

Що, як мого сервісу немає ні в списку, ні в каталозі?

Текст — будь-який OpenAI-сумісний сервіс. Кадри й відео — «Своє API», озвучка — «Власний сервер», розпізнавання — «Своє API»: шаблон, опис JSON або «Налаштувати з документації (ШІ)». Або встав усе в «Помічник підключення».
