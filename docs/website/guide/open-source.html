Відкритий код і переробка під себе

З версії 2.1.0 YT Cartell Studio безкоштовна й з відкритим кодом (MIT). Тепер програма доступна кожному вайбкодеру — кожен може зробити з неї те, що хоче: забрати код, попросити ШІ змінити що завгодно й зібрати свою версію.

Що змінилося в 2.1.0

  • Без входу й підписок. Вхід через Telegram і перевірку підписки на канал і чат прибрано: завантажуй і користуйся. Канал YT Cartell лишається — для новин і спілкування, за бажанням.
  • Відкритий код. Код студії — у репозиторії gitkalenyuk/yt-cartell-studio-source під ліцензією MIT.
  • Готові збірки — там само, де й були: у релізах gitkalenyuk/yt-cartell-studio. Кнопка «Оновлення» в студії бере нові версії звідти.

Не плутай із Telegram-ботом: свій бот для сповіщень і керування з телефона нікуди не дівся — він необов'язковий і працює як раніше.

Зібрати з коду

Студія написана на Go: увесь інтерфейс, генерація й монтаж — в одному файлі програми, без браузера й Node.js. Для монтажу їй, як і готовій збірці, потрібен FFmpeg — його можна поставити кнопкою в самій студії.

Windows

  1. Встанови Go 1.27 або новіший і Git.
  2. Склонуй код (або спершу зроби Fork на GitHub і клонуй свій):
    git clone https://github.com/gitkalenyuk/yt-cartell-studio-source
cd yt-cartell-studio-source
  3. Запусти build.bat. Поруч з'явиться YT-Cartell-Studio.exe. Версію можна передати аргументом: build.bat 2.1.0.

Збірка не підписана сертифікатом, тож Windows може показати «Windows захистив ваш ПК» → «Докладніше» → «Виконати в будь-якому разі». Якщо збірка падає з помилкою запису — закрий запущену студію й спробуй знову.

macOS

  1. Встанови Go 1.27+ (brew install go або з go.dev) і Xcode Command Line Tools: xcode-select --install.
  2. Склонуй код, як вище.
  3. Запусти bash build-mac.sh — він збере «YT Cartell Studio.app» для Apple Silicon та Intel і запакує їх у zip у папці dist/mac. Лише для свого Mac: bash build-mac.sh --arch arm64. Усі параметри — bash build-mac.sh --help.

Mac-версію збирають лише на Mac: там графічній бібліотеці потрібен cgo, тож з Windows її не зібрати.

Де що лежить

Почни з ARCHITECTURE.md у корені репозиторію: там структура, правила проєкту й опис кожної частини. Дай його прочитати й своєму ШІ-агенту — так він менше помилятиметься. Кілька орієнтирів:

ПапкаЩо там
main.goточка входу програми
internal/appuiвікно, меню й екрани студії
internal/guiнабір елементів інтерфейсу, кольори й теми
internal/studioпроєкти й п'ять кроків: сценарій → план → розкадровка → відео й озвучка → монтаж
internal/llmтекстові ШІ-сервіси
internal/ttsсервіси озвучки
internal/glabs, internal/gemini, internal/providersкадри й відео: G-Labs Studio, Google і «Своє API»
internal/mediaFFmpeg і збирання готового фільму
internal/nleекспорт у DaVinci Resolve, Premiere, Final Cut та інші
internal/tgbot, internal/notifyсвій Telegram-бот і сповіщення
internal/configналаштування й ключі
internal/update, internal/versionоновлення з GitHub і номер версії

Свій канал оновлень

Кнопка «Оновлення» шукає нові версії в релізах gitkalenyuk/yt-cartell-studio. Якщо ти робиш свою версію, направ оновлення на свій репозиторій — інакше студія запропонує поставити поверх неї офіційну. Репозиторій задається під час збирання через ldflags:

go build -ldflags "-X ytcartell/internal/update.Owner=me -X ytcartell/internal/update.Repo=my-studio" .
  • Windows: build.bat підставляє їх сам, якщо задати змінні середовища:
    set UPDATE_OWNER=me
set UPDATE_REPO=my-studio
build.bat 2.1.0
  • macOS: допиши ці два -X … у рядок LDFLAGS у build-mac.sh (або попроси ШІ). Параметр --repo скрипта лише вказує, куди завантажувати zip із --upload.
  • Що має бути в релізі: тег з версією (наприклад v2.1.1), файли YT-Cartell-Studio-<версія>-windows-x64.exe, …-macos-arm64.zip / …-macos-x64.zip і SHA256SUMS.txt з їхніми контрольними сумами — без рядка в ньому студія оновлення не встановить.

Приклади запитів до ШІ

Відкрий папку з кодом у Claude Code, Codex, Cursor чи іншому агенті й пиши своїми словами — українською теж можна. Кілька ідей:

  • Прочитай ARCHITECTURE.md і коротко поясни мені, як влаштована студія і де що лежить. Нічого поки не змінюй.
  • Додай новий стиль кадрів «Українська витинанка»: опис для промтів і прев'ю в галереї стилів — так само, як в інших стилів.
  • Підключи мій сервіс озвучки за документацією API за цим посиланням: … Додай його в «Налаштування → Підключення» поруч з іншими.
  • Додай стартовий профіль автопілота «Мій канал»: Shorts 9:16, 45 секунд, стиль «Нуар», швидкий темп.
  • Зроби головний колір інтерфейсу синім замість помаранчевого — і в світлій, і в темній темі.
  • Переклади інтерфейс студії англійською і додай у налаштування перемикач мови інтерфейсу.
  • Додай на крок «Монтаж» новий перехід між сценами — «Спалах білого», як інші переходи.
  • Зроби так, щоб моя збірка оновлювалась із мого репозиторію релізів me/my-studio, а не з офіційного.
  • Збери програму через build.bat і виправ помилки збірки, якщо будуть.

Проси по одній зміні за раз, а після кожної — збирай і перевіряй. Працюєш у Git — роби коміт перед кожною новою зміною, щоб легко відкотитися.

Ліцензія

Код поширюється під ліцензією MIT: його можна використовувати, змінювати, поширювати й продавати свої версії, зокрема з закритим кодом. Умова одна — зберегти текст ліцензії з копірайтом у копіях. Гарантій немає: програма надається «як є». Повний текст — у файлі LICENSE репозиторію.

Сторонні сервіси й програми, з якими працює студія (G-Labs Studio, Google, ElevenLabs, FFmpeg та інші), мають власні умови — вони від ліцензії студії не змінюються.

Питання

Треба вміти програмувати?

Ні — у цьому й ідея. Описуєш зміну словами, а код пише ШІ-агент. Знадобиться лише встановити Go й запустити збірку.

Мої проєкти й ключі зміняться, якщо я запущу свою збірку?

Своя збірка читає ті самі налаштування й папку проєктів, що й офіційна, — вони лежать окремо від програми. Перед великими змінами зроби копію через перенесення налаштувань.

Потрібен вхід через Telegram?

Ні. З версії 2.1.0 входу через Telegram і перевірки підписки немає — студія відкривається одразу.

Можна запропонувати зміну в офіційну версію?

Так: зроби Fork, внеси зміну й відкрий Pull Request у репозиторій з кодом.
